Saya, Harith Nabil bin Farouk, calon rayuan bagi kemasukan ke Sarjana Muda Kejuruteraan Perisian di Universiti Kebangsaan Malaysia.

Tentang Saya

Saya berasal dari Shah Alam, Selangor. Minat saya dalam bidang komputer bermula sejak zaman sekolah apabila saya kerap mencuba idea sendiri dan membina laman web kecil.

Semasa di Pusat Asasi Sains Universiti Malaya (PASUM), saya mula membina projek perisian yang lebih praktikal. Saya menghasilkan TeleSearch untuk mengautomasikan carian unit sewa bagi ejen hartanah daripada ribuan mesej Telegram. Seterusnya, saya membangunkan Q-Up, sistem giliran digital berasaskan kod QR. Kami bawa sistem ini dan uji terus bersama pelanggan di kafetaria UM sebelum membawanya ke Pertandingan Inovasi Antara Asasi Malaysia (PITRAM 2026) dan memenangi Pingat Perak.

Kemahiran utama saya merangkumi pembangunan web full-stack menggunakan React, Node.js, Express, dan MongoDB, serta integrasi API seperti Google Gemini. Di samping menumpukan perhatian pada projek teknikal, saya memperoleh keputusan SPM 6A+ 3A dan dianugerahkan Anugerah Kecemerlangan Kokurikulum di UM.

Saya berhasrat menyambung pengajian dalam jurusan Kejuruteraan Perisian di UKM menerusi Trek Pembangunan Sistem Maklumat. Saya ingin mendalami reka bentuk seni bina perisian berskala besar dan belajar daripada pensyarah serta pakar industri agar dapat membina sistem maklumat yang mantap untuk kegunaan masyarakat.

Projek

Q-Up

Sistem pengurusan giliran maya masa nyata menggunakan WebSockets dan kod QR. Pelanggan mengimbas kod di kaunter untuk memantau giliran terus di telefon pintar, manakala staf menguruskan panggilan nombor melalui papan pemuka admin.

q-up-client.onrender.com

TeleSearch

Aplikasi carian senarai hartanah pintar yang membaca mesej teks dalam kumpulan Telegram, memproses butiran rumah secara automatik menggunakan model Gemini AI, dan memaparkan hasil carian berstruktur pada papan pemuka web setempat.

github.com/harithnabilf/telesearch
