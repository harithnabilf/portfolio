## Features

- **Single-Page Design:** Continuous scroll with calm typography and generous spacing.
- **Dark Theme:** Neutral charcoal background (`#111111`) with off-white text and restrained monochrome highlights.
- **Interactive Media & Showcase:** Highlighted achievements, project cards, and embedded media demos.
- **Animations:** Subtle scroll fade-ins powered by the native Intersection Observer API.
- **Zero Heavy Dependencies:** Lightweight HTML, CSS, and vanilla JS.

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build production assets
npm run build
```
